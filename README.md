# Контрольная работа по Java — ООП

Программа предназначена для учёта сотрудников и расчёта премий.

## Как работает

Класс `Employee` хранит имя, должность и зарплату сотрудника.  
Премия обычного сотрудника составляет 10% от зарплаты.

Класс `Manager` наследуется от `Employee` и дополнительно хранит размер команды (`teamSize`).  
Премия менеджера составляет 15% от зарплаты + 1000 за каждого человека в команде.

Все сотрудники хранятся в массиве `Employee[]`. Благодаря полиморфизму метод `calculateBonus()` автоматически вызывает нужную версию для `Employee` или `Manager`.

Через `instanceof` программа определяет менеджеров и выводит размер их команды.

`employeeCount` хранит количество созданных сотрудников, а `totalBonusBudget()` рассчитывает общую сумму всех премий.

## Использованные темы

- Инкапсуляция
- `static`
- Наследование
- `@Override`
- Полиморфизм
- `instanceof`
